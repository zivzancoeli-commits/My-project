# What it is
It's a 2D editor where you make your own levels, use keys to unlock locks, kill enemies, and have fun.

## What's in it
- The only button on the main screen that truly works is the level editor
- A level editor
- Enemies and spikes
- Coins
- Keys and locks
- Blocks
- And level stuff like checkpoints and spawnpoints

## How to play 
1. Go to https://zivzancoeli-commits.github.io/My-project/
2. Click Level editor
3. Press L and click "Level 1"
4. Press E
5. Have fun
